# NEON SERPENT

Неоновый рогалик-змейка в одном файле `index.html`. Без сборки, зависимостей и установки.

## Режимы

- **СПУСК** — процедурные этажи, портал открывается за еду, босс каждые 5 этажей.
- **АРЕНА** — бесконечные волны, магазин каждые 5 волн, мини-боссы.
- **КЛАССИКА** — чистая змейка: одно касание, один забег, только счёт.

## Управление

| Действие | Клавиатура | Мобильные |
| --- | --- | --- |
| Движение | Стрелки / WASD | Свайп |
| Рывок | Shift / Пробел | Кнопка «РЫВОК» |
| Пауза | Esc / P | Кнопка «II» |
| Звук | M | — |
| Заново | R | — |

## Механики

- Столкновение отрезает часть хвоста и даёт короткую неуязвимость.
- Рывок убивает обычных врагов; боссу нужно таранить ядро.
- Опыт открывает мутации, монеты тратятся на складе между этажами.
- Постоянные улучшения и змейки покупаются в Логове; прогресс хранится в `localStorage`.

## Автообновление

- Каждый push в `main` автоматически публикует игру через GitHub Actions → GitHub Pages.
- Игра проверяет `meta[name="game-version"]` на сервере и показывает кнопку «ОБНОВИТЬ», если доступна новая версия.
- Для выпуска новой версии измените `content` у `game-version` в `index.html` и отправьте изменения в `main`.

## Локальный запуск

Просто откройте `index.html` в браузере. Для проверки автообновления можно запустить локальный сервер:

```bash
python -m http.server 8765
```

Затем откройте `http://127.0.0.1:8765/`.
